# Контент Telegram-бота PadelKing

Этот файл — единственный источник текстов и турниров для бота.
После любого изменения перезапустите бот (Render → Manual Deploy / Restart).
Тексты поддерживают HTML (`<b>`, `<i>`, `<a href>`), эмодзи и переносы строк.
